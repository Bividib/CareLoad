- [ ] Repository clean
- [ ] Final commit pushed
- [ ] README checked
- [ ] Screenshots selected from `/images`
- [ ] Demo video or backup recording prepared
- [ ] `.env`, secrets, uploads, recordings, database journals, and temporary files excluded from Git

- [ ] Fixture mode tested
- [ ] Live mode tested where possible
- [ ] Database reset tested twice
- [ ] Full demo rehearsed three times
- [ ] Browser notifications disabled
- [ ] Unnecessary tabs closed
- [ ] Laptop charger connected
- [ ] Presenter controls and recovery checkpoints available
- [ ] Final lint, type-check, tests, build, and Playwright results recorded
