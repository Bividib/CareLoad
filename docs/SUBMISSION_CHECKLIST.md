# CareLoad submission checklist

- [ ] Repository clean
- [ ] Final commit pushed
- [x] README checked
- [ ] Screenshots selected from `/images`
- [ ] Demo video or backup recording prepared
- [x] `.env`, secrets, uploads, recordings, database journals, and temporary files excluded from Git
- [x] Synthetic-data disclaimer visible
- [x] Fixture mode tested
- [x] Live mode tested where possible (superseding final acceptance evidence)
- [x] Database reset tested twice
- [ ] Full demo rehearsed three times
- [ ] Browser notifications disabled
- [ ] Unnecessary tabs closed
- [ ] Laptop charger connected
- [x] Presenter controls and recovery checkpoints available
- [x] Final lint, type-check, tests, build, and Playwright results recorded

Unchecked items require the presenter or final remote Git operation. Automated
Playwright does not count as three manual rehearsals.
